# การวิเคราะห์ความแตกต่างด้านการมีงานทำและค่าจ้างเฉลี่ยของแรงงานไทย
## Thailand Labor Market Data Visualization Dashboard

แดชบอร์ดนี้พัฒนาขึ้นเพื่อวิเคราะห์ความสัมพันธ์และความแตกต่างระหว่าง **อัตราการมีงานทำต่อประชากรวัยแรงงาน** และ **ค่าจ้างเฉลี่ยของลูกจ้าง** ในประเทศไทย โดยใช้ **ข้อมูลจริงจาก Open Data API ของสำนักงานสถิติแห่งชาติ (NSO / data.go.th: ชุดข้อมูล `0706_02_0011` และ `0706_02_0019`)** ครอบคลุมช่วงปี พ.ศ. 2561 – 2568

3. **ภูมิภาค:** ทั่วประเทศ, กรุงเทพมหานคร, ภาคกลาง, ภาคเหนือ, ภาคใต้, ภาคตะวันออกเฉียงเหนือ

5. **เพศ:** รวม, ชาย, หญิง

  - **Card 1C:** วิดเจ็ตเลือกไตรมาส Q1-Q4 พร้อมไฟสถานะ API เชื่อมต่อสมบูรณ์

### Tab 2: วิเคราะห์ความแตกต่างของกลุ่มที่สนใจ
**เป้าหมาย:** เจาะลึกความเหลื่อมล้ำและค้นหากลุ่มประชากรที่มีความเสี่ยงหรือน่าสนใจเป็นพิเศษ
- **Target Group Selector:** แถบควบคุม 7 มิติ (ปี, ภูมิภาค, พื้นที่, เพศ, อายุ, การศึกษา, อุตสาหกรรม) วิเคราะห์แบบ Real-time
- **Card 3A (กราฟที่ 5 - Butterfly Chart):** การมีงานทำและค่าจ้างตามระดับการศึกษา (อัตราการมีงานทำ % แถบซ้ายสีชมพู vs ค่าจ้างเฉลี่ย ฿ แถบขวาสีม่วงเข้ม) แสดงจุดตัดความเหลื่อมล้ำอย่างชัดเจน
- **Card 3B (กราฟที่ 7 - Comparison Profile & Benchmark):** การเปรียบเทียบกลุ่มที่เลือกกับค่าเฉลี่ยประเทศ (National Benchmark) พร้อมระบบวิเคราะห์ความเสี่ยงอัตโนมัติ:
  - ⚠️ **เสี่ยงสูง (In-work Poverty):** อัตรามีงานทำสูงแต่ค่าจ้างต่ำ (เช่น ประถมศึกษา, มัธยมต้น)
  - ⭐ **มั่นคง/ทักษะสูง:** ค่าจ้างสูงกว่าค่าเฉลี่ยประเทศ (เช่น ปริญญาตรีขึ้นไป)
  - 🚨 **กลุ่มเปราะบาง:** ทั้งหางานยากและค่าจ้างต่ำ
- **Card 3C (กราฟที่ 6 - Gender Wage Gap by Age):** กราฟแท่งคู่เปรียบเทียบค่าจ้างเฉลี่ย ชาย vs หญิง แยกตาม 8 ช่วงอายุ
- **Card 4A (กราฟที่ 8 - Cohort Historical Trend Line):** กราฟแนวโน้มประวัติศาสตร์ของกลุ่มที่เลือก ย้อนหลัง 2561 – 2568 เพื่อพิสูจน์ว่าช่องว่างความแตกต่างเกิดขึ้นถาวรหรือชั่วคราว
- **Card 4B (Executive Policy Insights Panel):** แผงข้อสรุปเชิงนโยบาย ตอบคำถามหลัก 5 ข้อ พร้อมข้อเสนอแนะเชิงปฏิบัติการสำหรับกรมการจัดหางานและกรมพัฒนาฝีมือแรงงาน

## 🚀 3 วิธีในการเปิดใช้งาน Dashboard

### วิธีที่ 1: รันผ่าน Streamlit (แนะนำ)
```powershell
streamlit run app.py
```
> ระบบจะเปิดหน้าแดชบอร์ด **Ultra-Modern Bento Grid** โดยอัตโนมัติ (และมีเมนูด้านข้างให้สลับไปดูแบบ Plotly เดิมได้หากต้องการ)

### วิธีที่ 2: รันผ่าน Local Python Server (เร็วที่สุด ไม่ต้องมี Streamlit)
```powershell
python server.py
```
> ระบบจะเปิดหน้าเว็บเบราว์เซอร์ (Chrome / Edge) ไปที่ `http://localhost:8501` ทันทีด้วยดีไซน์เว็บโมเดิร์นแบบเต็มหน้าจอ

### วิธีที่ 3: ดับเบิลคลิกไฟล์ HTML โดยตรง
ดับเบิลคลิกเปิดไฟล์ `dashboard.html` ในโฟลเดอร์โปรเจกต์ผ่านเว็บบราวเซอร์ใดก็ได้ทันที (ข้อมูลถูกบรรจุภายในไฟล์แบบ Standalone ไม่ต้องต่ออินเทอร์เน็ตเพื่อดึงดาต้า)

## 💡 สรุปผลการวิเคราะห์เชิงลึก (Key Findings)
1. **ภาวะ In-work Poverty:** แรงงานที่มีการศึกษาระดับประถมศึกษามีอัตราการมีงานทำสูงที่สุดถึง **73.9%** แต่กลับได้รับค่าจ้างเฉลี่ยต่ำที่สุดเพียง **~9,730 บาท/เดือน** ในทางกลับกัน กลุ่มปริญญาตรีมีอัตรามีงานทำ **82.1%** แต่ได้รับค่าจ้างสูงถึง **27,367 บาท/เดือน**
2. **ความเหลื่อมล้ำเชิงพื้นที่ (Spatial Wage Disparity):** ค่าจ้างเฉลี่ยในกรุงเทพมหานคร (26,913 บาท) สูงกว่าภาคตะวันออกเฉียงเหนือ (12,816 บาท) ถึง **2.1 เท่า (110%)**
3. **ช่องว่างค่าจ้างระหว่างเพศ (Gender Wage Gap):** ในช่วงอายุ 15-24 ปี ค่าจ้างระหว่างชายและหญิงใกล้เคียงกัน แต่เริ่มถ่างกว้างขึ้นชัดเจนตั้งแต่อายุ 35 ปีขึ้นไป โดยเพศชายมีอัตราค่าจ้างเฉลี่ยสูงกว่าเพศหญิง
