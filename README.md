# Thailand Labor Market Intelligence

Dashboard เชิงโต้ตอบสำหรับวิเคราะห์ **การว่างงาน การมีงานทำ และค่าจ้าง** ของประเทศไทยด้วย **ข้อมูลสาธารณะจริง** จาก NSO, สศช., ธปท. และสำนักงานประกันสังคม
(โฟลเดอร์นี้รวมโปรเจกต์ Thailand Unemployment Intelligence Dashboard เข้ากับ thailand-labor-market-dashboard โดยโฟลเดอร์ต้นฉบับทั้งสองไม่ถูกแก้)
สร้างด้วย Python + Streamlit + Pandas + Plotly

> **หลักการสำคัญ:** ระบบไม่สร้างหรือประมาณข้อมูลขึ้นเอง ถ้าดึงข้อมูลไม่ได้หรือข้อมูลไม่ผ่านการตรวจสอบ จะแสดงข้อความอธิบายแทนตัวเลข
> ข้อมูลทดสอบ (fixture) มีอยู่เฉพาะใน `tests/` เท่านั้น และ Dashboard ไม่เคยอ่านมัน

## สิ่งที่ต้องรู้ก่อนใช้งาน (ผลการตรวจสอบแหล่งข้อมูล)

- Dataset `0706_02_0011` ที่ระบุในโจทย์ตั้งต้นบน data.go.th คือ **"อัตราการมีงานทำต่อประชากรวัยแรงงาน"** (ร้อยละ) ไม่ใช่จำนวนผู้ว่างงาน
  โปรเจกต์จึงใช้ Dataset ในตระกูลเดียวกันของ NSO: `0706_02_0003` (จำนวนผู้ว่างงาน), `0706_02_0016` (อัตราการว่างงาน), `0706_02_0001` (กำลังแรงงาน), `0706_02_0002` (ผู้มีงานทำ)
- **อัตรามีงานทำ (`0706_02_0011`) และค่าจ้าง (`0706_02_0019`) ใช้ในหน้า ค่าจ้างและเศรษฐกิจ / กลุ่มประชากร / รายภูมิภาค** โดยดึงตาราง สสช. 6 ตารางและตรวจข้ามตาราง: ค่าจ้างเฉลี่ยประเทศของ 7 ไตรมาส (2567 Q1 – 2568 Q3)
  ขัดแย้งกันเองระหว่างตาราง จึงเว้นเป็นช่องว่างในทุกกราฟ ไม่เลือกตารางใดตารางหนึ่งเป็นฝ่ายถูก
- จำนวนผู้มีงานทำ (แสดงเป็นคน) ปี 2563–2569 ดึงตรงจากตาราง สสช. `OS_02_0002_01` (ชุด `0706_02_0002`) ระบบตรวจกับตาราง `LFS_02_20535_1` ทุกครั้งที่โหลด
- รายละเอียดทั้งหมด: [docs/SOURCE_VERIFICATION.md](docs/SOURCE_VERIFICATION.md)

## วิธีดึงข้อมูลจริง / Refresh

- **อัตโนมัติ:** ครั้งแรกที่เปิดแอป ระบบดาวน์โหลดไฟล์ที่ยังไม่มีไปไว้ที่ `data/raw/`
- **ปุ่ม Refresh Data** ที่มุมขวาบน: ดึงข้อมูลใหม่ทุกแหล่ง ถ้าแหล่งใดล้มเหลว **ข้อมูลเดิมถูกเก็บไว้** และ Header จะแจ้งว่ากำลังใช้ข้อมูล Cache พร้อมเวลาที่ดึงสำเร็จครั้งล่าสุด (จะไม่ใช้คำว่า "ข้อมูลล่าสุด" เมื่อใช้ Cache เก่า)
- **ผ่านบรรทัดคำสั่ง:**
  ```powershell
  python -c "from data_sources.downloader import refresh_all; r = refresh_all(); print(r.n_ok, 'ok'); [print(f.key, f.error_kind, f.error) for f in r.failures]"
  ```
- ข้อมูลที่เก่ากว่า `TUI_STALE_AFTER_DAYS` (ค่าเริ่มต้น 7 วัน) จะถูกติดป้ายเตือนว่าเก่า

## วิธีเปลี่ยน URL แหล่งข้อมูลผ่าน Configuration

รายการแหล่งข้อมูลอยู่ใน `config.py` (`SOURCES`) สามารถแทน URL ได้โดยไม่แก้โค้ด ผ่านตัวแปรสภาพแวดล้อม `TUI_URL_<KEY>` หรือไฟล์ `.env` (คัดลอกจาก `.env.example`):

```
TUI_URL_NESDC_GDP=https://www.nesdc.go.th/wordpress/wp-content/uploads/2026/03/ChainVolumeMeasures.xlsx
TUI_STALE_AFTER_DAYS=14
```

ค่า `KEY` ดูได้จาก `config.py` เช่น `NSO_U_REGION`, `NESDC_GDP`, `SSO_BENEFIT`
ไฟล์ GDP และ SSO ระบบหา URL ล่าสุดจาก CKAN API ของ data.go.th ให้อัตโนมัติ เว้นแต่คุณกำหนด URL เอง

## วิธีแก้ปัญหาเมื่อดึงข้อมูลไม่ได้

| อาการ | สาเหตุที่พบบ่อย | วิธีแก้ |
|---|---|---|
| "ปัญหาการเชื่อมต่อเครือข่าย" | อินเทอร์เน็ต/ไฟร์วอลล์/เซิร์ฟเวอร์ต้นทางล่ม | ตรวจเครือข่าย แล้วกด Refresh Data (ข้อมูลเดิมยังอยู่) |
| `HTTP 418/403` | WAF ของ NSO ปฏิเสธ User-Agent | ระบบส่ง User-Agent ที่ระบุตัวตนไว้แล้ว (`TUI_USER_AGENT` ปรับได้) อย่าใช้ UA ของ `python-requests` ค่าเริ่มต้น |
| "ไฟล์ที่ได้รับไม่ถูกต้อง" | URL เปลี่ยน หรือได้หน้า HTML แทนไฟล์ | ตรวจ URL ที่ data.go.th แล้วตั้ง `TUI_URL_<KEY>` |
| "ข้อมูลไม่ผ่านการตรวจสอบคุณภาพ" | โครงสร้าง/หน่วยในไฟล์ต้นฉบับเปลี่ยน | ดูรายละเอียดในแท็บ Data Sources & Methodology และ `logs/app.log` |

ปัญหาเครือข่ายและปัญหาคุณภาพข้อมูลแสดงแยกกันคนละข้อความ

## หน้าตาและหน้าต่าง ๆ (3 แท็บในแบนเนอร์ + แถบกรองด้านซ้าย)

- **แถบกรองด้านซ้าย** (พับได้บนมือถือ): ปี (พ.ศ.) ไตรมาส ภูมิภาค เพศ ระดับการศึกษา และปุ่มรีเซ็ต · มีปุ่มรีเฟรชข้อมูลและดาวน์โหลดรายงานสรุป
- **แบนเนอร์ด้านบน**: ชื่อ ช่วงข้อมูล พื้นที่ศึกษา อัปเดตล่าสุด สถานะข้อมูล และปุ่ม "ที่มา วิธีการ และหลักฐาน" (เปิดเป็นหน้าต่างซ้อน: หลักฐานสาเหตุการว่างงาน และแหล่งข้อมูลและวิธีการ) พื้นหลังเป็นสีไล่เฉด (ไม่ใช้รูปภาพ)

1. **ภาพรวม** — การ์ดไล่สี 4 ใบ (อัตรามีงานทำ อัตราการว่างงาน ค่าจ้างเฉลี่ย จำนวนผู้มีงานทำ พร้อมเส้นแนวโน้มและเทียบปีก่อน), แผนที่ภูมิภาค (สลับตัวชี้วัดได้), แนวโน้มรายไตรมาส, ภูมิภาคที่ค่าจ้างสูงสุด, ค่าจ้างชาย-หญิงตามอายุ, ภูมิภาคที่ว่างงานสูงสุด (จัดอันดับ 5 ภาค), ความสัมพันธ์ค่าจ้าง-การว่างงาน (พร้อม r), สรุปจากข้อมูล 4 ข้อ (สร้างจากตัวเลขอัตโนมัติ) และส่วนขยาย: เปรียบเทียบสองภาค/สองไตรมาส, แนวโน้ม 3 ตัวชี้วัดแบบละเอียด / เทียบกับ GDP
2. **ภูมิภาค** — แท็บย่อย: การว่างงานรายภาค (แผนที่ แนวโน้ม รายจังหวัด) · ค่าจ้างและการมีงานทำรายภาค
3. **กลุ่มแรงงาน** — แท็บย่อย: การศึกษา · เพศ · กลุ่มอายุ · จำนวนผู้มีงานทำ

ทุกตัวเลขมาจากตารางที่ผ่านการตรวจสอบ ไตรมาสที่ไม่มีค่าที่เชื่อถือได้เป็นช่องว่าง และการ์ดที่ค่าล่าสุดเก่ากว่าไตรมาสที่เลือกจะบอกไตรมาสของค่านั้นไว้เอง

- **แถบ "ข้อมูลในหน้านี้"** ใต้การ์ดบอกว่าแต่ละส่วนของหน้าภาพรวมใช้ไตรมาสใด ส่วนที่เก่ากว่าการ์ดเป็นสีส้ม
- **ขอบเขตข้อมูล: พ.ศ. 2563–2569** (ตัดข้อมูลก่อน 2563 ออกที่ `config.SCOPE_START_BE`; ก่อนหน้านั้นอัตรามีงานทำและค่าจ้างรายภาคว่างเกือบทั้งหมด และตัวเลขผู้มีงานทำตรวจกับ สสช. ไม่ได้) กราฟแนวโน้มแสดงทั้งช่วงนี้เสมอ ช่วงปีที่เลือกในตัวกรองถูกแรเงาไว้
- **แผนที่** ใช้สีประจำภาค (แต่ละภาคหนึ่งสี) ค่าของแต่ละภาคอยู่ในรายการข้างแผนที่ เรียงจากมากไปน้อย
- อินโทรเล่นครั้งแรกในแต่ละเบราว์เซอร์ (เล่นซ้ำได้จากเมนูตั้งค่า) · ปิดมาสคอตได้จากเมนูตั้งค่า และบนมือถือซ่อนไว้เสมอ

ทุกตารางมีปุ่มดาวน์โหลด CSV (UTF-8 BOM เปิดใน Excel ภาษาไทยได้) และ แถบบนมีปุ่ม ℹ️ (วิธีอ่านและข้อจำกัด), 🔄 รีเฟรช และ ⬇ ดาวน์โหลดรายงานสรุป (.md) และกล่อง "☰ ตัวกรอง" ที่พับอยู่ (ป้ายบอกตัวกรองปัจจุบัน) กดเพื่อเปิด: ปีเริ่มต้น/สิ้นสุด ไตรมาส ภูมิภาค เพศ ระดับการศึกษา

## ข้อจำกัดของการวิเคราะห์

- แผนที่ภูมิภาคใช้ได้ปี 2563 เป็นต้นไป (ปีที่ สสช. เผยแพร่นิยามจังหวัด→ภาค) แสดง 5 ภาค (กรุงเทพฯ เหนือ ตะวันออกเฉียงเหนือ กลาง ใต้) คลิกภาคบนแผนที่เพื่อขยายและกรองทั้งหน้า; ตั้งแต่ปี 2568 ที่ สสช. แยก 7 ภาค จะรวมภาคตะวันออกเข้าภาคกลาง และใต้ชายแดนเข้าภาคใต้ (จังหวัดชุดเดียวกัน); ขอบเขตจังหวัดเป็นปีอ้างอิง 2560

- ข้อมูลมาจากการสำรวจตัวอย่าง มีความคลาดเคลื่อนจากการสุ่ม โดยเฉพาะเมื่อแยกหลายมิติและระดับจังหวัด
- ข้อมูลรายไตรมาสไม่ปรับฤดูกาล ใช้ YoY เป็นหลักในการตีความ
- NSO แยกภาคเป็น 7 ภาคในปี 2568: ผู้ว่างงาน/กำลังแรงงานรวมกลับเป็น 5 ภาคได้ตรง ๆ แต่อัตรามีงานทำและค่าจ้างของภาคกลาง/ใต้ปี 2568+ รวมไม่ได้ (ไม่มีตัวถ่วงน้ำหนัก) จึงเป็นช่องว่าง
- ตารางต้นฉบับบางไตรมาสไม่สอดคล้องกันเอง ระบบตรวจพบและยกเว้นไตรมาสนั้นแทนการแก้ตัวเลข (ดูรายงานการตรวจสอบ)
- ตัวกรอง ภาค+เพศ+การศึกษา พร้อมกันใช้ตารางข้ามมิติซึ่งเริ่มปี 2561 และอัตรารายระดับการศึกษาคำนวณเฉพาะระดับประเทศ
- ไม่มีข้อมูลสาเหตุการว่างงานโดยตรงของประชากรทั้งประเทศ: เหตุผลที่ออกจากงานเดิมมีถึง Q4/2565 และข้อมูลประกันสังคมเป็น Proxy (ผู้ประกันตนเท่านั้น, ปี 2563–2565)
- GDP ในไฟล์ที่เผยแพร่ล่าสุดถึง Q4/2568 จึงไม่ถูกจับคู่กับการว่างงานปี 2569
- ความสัมพันธ์ระหว่าง GDP กับการว่างงานเป็นเพียง Correlation ไม่ใช่การพิสูจน์สาเหตุ

3. แอปจะดึงข้อมูลจริงเองในการเปิดครั้งแรก (ไม่ต้องอัปโหลดข้อมูล) และใช้ปุ่ม Refresh Data เมื่อต้องการข้อมูลใหม่
4. หากต้องการปรับค่า (เช่น URL) ให้ตั้งใน Secrets/Environment ของ Streamlit Cloud ในชื่อ `TUI_URL_<KEY>`

หมายเหตุ: ดิสก์ของ Streamlit Cloud ไม่ถาวร Cache จะหายเมื่อแอปถูก Restart แล้วระบบจะดึงใหม่

**Docker / เซิร์ฟเวอร์ของตนเอง:** ติดตั้ง `requirements.txt` แล้วรัน `streamlit run app.py --server.port 8501 --server.headless true` หลัง Reverse Proxy
ควรเมานต์โฟลเดอร์ `data/` เป็น Volume เพื่อคง Cache ข้ามการ Restart

## แหล่งข้อมูล

ข้อมูลทั้งหมดเป็นข้อมูลสาธารณะ ผู้ใช้ต้องอ้างอิงหน่วยงานเจ้าของข้อมูลตามเงื่อนไขของแต่ละ Dataset (ดูหน้า Data Sources & Methodology)

- สำนักงานสถิติแห่งชาติ (NSO) ผ่าน <https://data.go.th> และ <https://catalogapi.nso.go.th>
- สำนักงานสภาพัฒนาการเศรษฐกิจและสังคมแห่งชาติ (สศช.) — GDP รายไตรมาส
- ธนาคารแห่งประเทศไทย (ธปท.) — เหตุผลที่ผู้ว่างงานออกจากงาน (ที่มา: NSO)
- สำนักงานประกันสังคม — ผู้ใช้สิทธิประโยชน์กรณีว่างงาน
- geoBoundaries (geoLab, William & Mary; ข้อมูลจาก OpenStreetMap) — ขอบเขตจังหวัดสำหรับแผนที่ สัญญาอนุญาต Open Database License 1.0 ต้องอ้างอิงแหล่งที่มา <https://www.geoboundaries.org/>

## ฟีเจอร์เสริมการนำเสนอ

- **เปรียบเทียบ:** ในส่วน "รายละเอียดเพิ่มเติม" เลือกเทียบสองภูมิภาค (เส้นกราฟสีประจำภาค) หรือสองไตรมาส (ตารางแสดงการเปลี่ยนแปลง)
- **โหมดมืด:** สวิตช์ในเมนูตั้งค่า (ไอคอนฟันเฟืองบนแถบซ้าย)
- **ฟอนต์ Kanit ในโปรเจกต์:** `static/fonts/` (ใบอนุญาต SIL OFL) ใช้ได้โดยไม่ต้องต่ออินเทอร์เน็ต
- **เปิดเร็วขึ้น:** ตารางที่ประมวลผลแล้วเก็บไว้ที่ `data/processed/bundle.pickle` (สร้างใหม่อัตโนมัติเมื่อข้อมูลต้นทางหรือโค้ดประมวลผลเปลี่ยน) เปิดครั้งแรกหลังรีสตาร์ตเหลือประมาณ 3 วินาที
- **คลิปแชร์ 10 วินาที:** `python tools/make_share_video.py` สร้าง `docs/share_labour_market.mp4` จากตัวเลขล่าสุดด้วย HyperFrames (ต้องมี Node, Chrome, FFmpeg)

## หน้าอินโทร (HyperFrames)

หน้า motion graphics ก่อนเข้าแดชบอร์ดเป็นคอมโพสิชันของ [HyperFrames](https://hyperframes.heygen.com) (HTML + CSS + GSAP ที่เล่นทีละเฟรมได้) ไฟล์ต้นทางอยู่ที่ `dashboard/intro.py`
- **ในแอป:** ไม่เล่นแล้ว (เอาออกตามที่ขอ) คอมโพสิชันยังอยู่เพื่อใช้สร้างวิดีโอ ตัวเลขมาจาก `data/processed/intro_payload.json` ที่เขียนใหม่ทุกครั้งที่โหลดข้อมูล
- **เป็นไฟล์วิดีโอ:** `docs/intro_labour_market.mp4` (1920×1080, 30 fps, 10 วินาที) สร้างใหม่ได้ด้วย
  1. `npx hyperframes init labour-intro --example blank` แล้ว `python tools/build_intro.py labour-intro` (เขียน `index.html` พร้อมตัวเลขล่าสุด)
  2. `cd labour-intro && npx hyperframes render --workers 2 --output intro.mp4` (ต้องมี Node, Chrome และ FFmpeg; `npx hyperframes doctor` ตรวจให้)
